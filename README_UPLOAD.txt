STOPAZ responsive Jew-Hatred site

Upload every file and folder inside this directory to the root of the GitHub repository.
Do not upload only the ZIP file.

Pages
- index.html: Jew-Hatred homepage
- antijudaism.html: temporary three-item gallery
- antisemitism.html: temporary three-item gallery
- exhibition.html: the existing Antizionism exhibition, visually and textually preserved, with only audio/language continuity and page-transition support added

Responsive layout
- Laptop and desktop: three cards left to right
- Phone: large cards top to bottom, almost edge to edge

Interactions
- Slow image enlargement and brighter color on hover
- Cards and description boxes lift and move subtly
- Titles, author/source, date, and descriptions type letter by letter as they enter view
- Click any gallery image to enlarge it
- Music starts after the first user interaction, then attempts to continue from the same position after internal page changes
- EN, HE, and RU choices persist between pages
- Internal navigation uses a gallery-style fade/curtain transition

Browser rule
Browsers do not permit sound before the visitor interacts. The first click or key press enables the music. If a browser blocks automatic resume after navigation, the next click resumes it.

Temporary content
Unknown titles, creators, dates, descriptions, and citations remain marked as pending. No metadata was invented. Additional uploads are stored in pending-materials.
